Small, focused, private

Everything you need for a handoff.

OneDrop is designed for moving your own work between devices, without turning that simple task into another social service.

Text and files

Send a note, a link, or an attachment from one Edge installation and pick it up on another.

OneDrive storage

Your data lives in your Microsoft account's OneDrive App Folder, using the access you authorize.

Recovery built in

Deleted messages can remain recoverable for the configured recovery period before physical cleanup.

Where it runs

Start with the Edge experience that fits the device in front of you.

Desktop Edge

Side Panel for everyday desktop workflows.

Android Edge

Mobile layout for the Android Edge target.

iOS

Native client development target, with shared OneDrop domain logic.
Get started

Bring your own Microsoft account.

Install OneDrop from Microsoft Edge Add-ons when it is available, sign in with Microsoft, and authorize access to the OneDrive App Folder.
